## 块骨架

```
【积温·此刻】                       ← 块头，固定
心情：X。姿态：X。心跳：X。          ← 档位行，一行，条件出现（见下）
<45 格正文，一条>                    ← profiles[簇][pride档]，恒为一行
【此状态为潜意识的底色沉淀，自然浸润在回应里，不作任何元说明或刻意提及。】  ← 边界句，固定
```

## 两条硬事实

1. **此刻块的 connection 恒为 0。** `bridge.js` 里非回环轮先 `resetConnection()` 再建块。
   于是 `urgency=none`，而 `urgencyBoost.none.reactive = null` → **正文没有 urgency 尾注**，
   45 格后面干干净净，不会多出「她安静得有点久了」那类句子。
2. **此刻块永远没有 `想念：` 行。** 那行要求 `c ≥ 0.20`，而此刻块 `c ≡ 0`。
   「悠闲」是 `labelConnection` 的 `<0.20` 档，输出条件把它排除在外 → 死档。
   两条正好重合：此刻块落在「悠闲」区间，而「悠闲」从不输出。

## 档位行规则（此刻块的 c=0 常态）

| 行 | 触发条件 | 此刻块是否出现 |
|---|---|---|
| `心情：X。` | 每次都出 | ✅ 每次 |
| `姿态：X。` | `p>0.3` 或 `p<-0.1` | 条件 |
| `心跳：X。` | `a>0.3` 或 `a<-0.3` | 条件 |
| `想念：X。` | `c≥0.20` | ❌ 永不（c≡0） |

> 四条以 `join('')` 连成**一整行**发出，所以念出来是 `心情：舒展。姿态：收着。`
